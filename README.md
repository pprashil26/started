# Started V1.0.2

Strict chronological Timeline release built from the locked V1.0.1 Responded baseline.

## GitHub Pages deployment
Upload index.html, manifest.webmanifest, service-worker.js, and all icon files to the same GitHub Pages folder. Paths are relative and safe for project-site deployment. Open the published site online once before installing the PWA.

## V1.0.2
Started tasks sort earliest to latest within each week. Critical, lifecycle, Active, Responded and Completed states do not change Timeline position. Not Started remains separate and sorts A-Z. StartedDB remains version 1 and backup format remains version 1.
