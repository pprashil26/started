# Started V1.0

One-screen local-first PWA for tracking task start and completion timestamps.

## Deploy on GitHub Pages
Upload all files in this folder to the same repository folder. Set GitHub Pages to deploy from that branch/folder. Paths are relative and safe for project sites. Open the published page once online before installing so the service worker can cache the app shell.

## Files
- index.html
- manifest.webmanifest
- service-worker.js
- icon PNG files

## Data
IndexedDB: StartedDB v1, store: tasks. Backup and restore are available from the overflow menu.
